# 🎵 Musicify

A full-stack music streaming application where users can upload, manage, and listen to their own music.

**Live Demo:** https://musicify-tan.vercel.app/

## Features
- User authentication
- Upload and play music
- Create and manage playlists
- Store music files using Supabase Storage

## Tech Stack
- **Frontend:** React, Vite, CSS
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Storage:** Supabase
- **Authentication:** JWT, HTTP-only Cookies
- **Deployment:** Vercel, Render

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure your environment variables.
4. Start the backend and frontend using `npm run dev`.

## Deployment
- Frontend: Vercel
- Backend: Render
